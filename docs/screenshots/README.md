# Thư mục Ảnh Chụp Màn Hình (Screenshots)

Thư mục này lưu trữ hình ảnh minh họa giao diện hệ thống hiển thị trong `README.md` trên GitHub.

## Danh sách ảnh khuyến nghị chụp:

1. `01-ban-hang-pos.png`: Màn hình giao diện bán hàng / chọn món (màn hình chính cho thu ngân / phục vụ, chạm chọn món, giỏ hàng, tùy chỉnh topping).
2. `02-so-do-ban.png`: Màn hình sơ đồ bàn theo khu vực (trạng thái bàn trống, có khách, bàn mở ca).
3. `03-thanh-toan-vietqr.png`: Modal thanh toán VietQR động (hiển thị mã QR NAPAS247 kèm số tiền chính xác và bộ đếm thời gian).
4. `04-quan-ly-ca.png`: Màn hình mở/đóng ca làm việc và kiểm kê tiền mặt (bàn giao ca).
5. `05-bao-cao-doanh-thu.png`: Biểu đồ doanh thu theo ngày/tháng và các số liệu trực quan.

## Khuyến nghị thông số ảnh:
- **Tỉ lệ / Độ phân giải**: 1920x1080 (Full HD) hoặc chụp cửa sổ trình duyệt tối thiểu 1280x720.
- **Định dạng**: `.png` (nén qua tinypng hoặc tương đương để dung lượng < 500KB mỗi ảnh) hoặc ảnh động `.gif`.
- **Dữ liệu hiển thị**: Sử dụng dữ liệu mẫu phát triển (`npm run db:seed` và `npm run seed:menu`), không chụp dữ liệu khách hàng thực tế.
